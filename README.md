# 🧳 Travel Planner Bot

Telegram-бот для планирования отдыха: подбирает авиабилеты и следит за ценами, ищет жильё с учётом состава группы и питомцев, предлагает экскурсии, рестораны и достопримечательности, составляет план поездки по дням.

Бот личный: пользоваться им могут только пользователи из белого списка.

## Стек

- **Java 17+**, **Spring Boot 4**
- [TelegramBots](https://github.com/rubenlagus/TelegramBots) (long polling)
- **PostgreSQL** + **Flyway** (миграции), Spring Data JPA
- **JUnit 5**, Mockito, AssertJ, **Testcontainers**
- **Docker**, docker-compose, GitHub Actions (CI)

## Архитектура

```
Telegram ──► TelegramUpdateConsumer ──► CommandRouter ──► сервисы ──► внешние API
             (адаптер Telegram API)     (логика бота)     (AccessService, …)
                                                │
                                                ▼
                                           PostgreSQL
```

- `bot/telegram` — единственное место, которое знает о Telegram API. Остальной код работает с простыми объектами `IncomingMessage` / `BotReply`, поэтому логика бота покрыта unit-тестами без подключения к Telegram.
- `user` — белый список и роли (`ADMIN`, `USER`).
- `dialog` — анкета «Новая поездка» как конечный автомат; текущий шаг хранится в базе, поэтому перезапуск бота не сбрасывает анкету. `DateRangeParser` понимает даты в привычной записи: `12.05–18.05`, `12–18 мая`, `28 декабря - 5 января`.
- `trip` — поездки, их описание для сообщений (`TripFormatter`) с правильным склонением: «2 взрослых, 1 ребёнок (5 лет), 6 ночей».
- `config` — типизированные настройки (`@ConfigurationProperties`).

## Возможности и план разработки

- [x] **Этап 1.** Каркас: подключение к Telegram, белый список с ролями, главное меню, Docker, CI
- [x] **Этап 2.** Новая поездка: анкета (куда, откуда, даты, взрослые, дети и их возраст, питомцы, бюджет), список и удаление поездок
- [ ] **Этап 3.** Авиабилеты: поиск и календарь самых дешёвых цен (Aviasales Data API)
- [ ] **Этап 4.** Отслеживание цен на билеты: подписки, проверка по расписанию, уведомления о снижении цены
- [ ] **Этап 5.** Жильё: ссылки на поиск с фильтрами (ЦИАН, Авито, Суточно), предложения Островка
- [ ] **Этап 6.** Достопримечательности, рестораны, экскурсии (OpenTripMap, Foursquare, Tripster, Sputnik8)
- [ ] **Этап 7.** План поездки по дням, графики цен, деплой

## Как выглядит анкета

```
🗺 Куда едем?                → Италия, Рим
🛫 Откуда отправляетесь?     → [Москва] [Санкт-Петербург]
🗓 Когда?                     → 12–18 мая
👥 Сколько взрослых едет?    → [1] [2] [3] [4] …
🧒 А детей?                   → [Нет] [1] [2] [3]
   Сколько лет детям?         → 5, 8
🐾 Берёте с собой питомца?   → [Нет] [🐕 Собака] [🐈 Кошка] [🐾 Другое]
💰 Бюджет на жильё за ночь?  → [до 3 000 ₽] [до 6 000 ₽] [до 10 000 ₽] [Неважно]

Проверьте, всё ли верно:
📍 Италия, Рим
🛫 Откуда: Москва
🗓 12 мая – 18 мая 2027 (6 ночей)
👥 2 взрослых, 2 ребёнка (5, 8 лет)
🐾 С собакой
💰 Жильё до 6 000 ₽ за ночь
                              → [✅ Сохранить] [🔄 Заново]
```

На неверный ответ бот объясняет, что не так, и повторяет вопрос.

## Команды бота

| Команда | Кто может | Что делает |
|---|---|---|
| `/start` | пользователи | главное меню |
| `/newtrip` | пользователи | новая поездка (то же, что кнопка «🗺 Новая поездка») |
| `/cancel` | пользователи | отменить заполнение анкеты |
| `/mytrips` | пользователи | сохранённые поездки |
| `/deletetrip <номер>` | пользователи | удалить поездку по номеру из `/mytrips` |
| `/help` | пользователи | список команд |
| `/myid` | все | показывает Telegram ID (чтобы передать его администратору) |
| `/allow <ID>` | администратор | дать доступ |
| `/deny <ID>` | администратор | забрать доступ |
| `/users` | администратор | список пользователей |

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Скопируйте настройки и заполните их:
   ```bash
   cp .env.example .env
   ```
   В `ADMIN_IDS` укажите свой Telegram ID. Если вы его не знаете, запустите бота, отправьте ему `/myid`, впишите ID и перезапустите бота.
3. Запустите бота вместе с базой:
   ```bash
   docker compose up -d --build
   ```

### Локальная разработка

```bash
docker compose up -d db          # только PostgreSQL
./mvnw spring-boot:run           # переменные BOT_TOKEN, ADMIN_IDS и др. задайте в IDE или окружении
```

### Тесты

```bash
./mvnw test
```

Интеграционные тесты поднимают PostgreSQL в Docker через Testcontainers. Если Docker не запущен, они пропускаются.
